# Sideby Parent web

Next.js parent workspace with Neon Auth, Postgres, private Object Storage and Realtime. Run commands from the repository root. See [setup](../../docs/NEON_SETUP.md), [API](../../docs/API.md) and [verification](../../docs/VERIFICATION.md).

The web app manages family profiles and saved preferences. No phone is monitored or controlled by this version. Device pairing and the Android companion are future work.
