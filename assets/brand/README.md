# Sideby brand assets

Two open, rounded links sit side by side and form an abstract S. Teal conveys steadiness; coral adds warmth. Keep the companion clearly identifiable as Sideby Connect.

| Asset | Use |
| --- | --- |
| `wordmark.svg` | Main logo on light backgrounds |
| `wordmark-dark.svg` | Main logo on dark backgrounds |

## Usage

Keep clear space of at least one stroke width around the symbol. Use the standalone symbol below 140 px logo width; use at least 24 px for general UI icons. The favicon is a simplified monochrome variant. Do not stretch, rotate, add shadows, or use low-contrast backgrounds. Mark decorative patterns as decorative in applications.

Wordmarks use live Arial/Helvetica text with a sans-serif fallback; appearance can vary by platform. Outline the text before final print delivery. SVG is the editable source format. Raster social previews and native mobile/adaptive app-icon exports are still needed at integration time; SVG social metadata is not universally supported.

Assets were authored directly as vectors, extending the repository identity; no raster image generation or tracing was used. Trademark clearance remains outstanding.
